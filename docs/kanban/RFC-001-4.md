# ApiKey — migrar DTOs para entidade direta

## Contrato de Entrada
- `POST /projects/{projectId}/api-keys`: `{ name: string (max 255), expiresInDays?: int positivo }`.
- `PATCH /api-keys/{id}`: `{ name?: string }`.
- `DELETE /api-keys/{id}`: soft-delete, requer `X-Security-Key` do parceiro dono ou Master.
- `projectId`: ID prefixado do Project (`prj_...`).

## Contrato de Saída
- `GET /projects/{projectId}/api-keys`, `GET /api-keys/{id}` e PATCH serializam no grupo `api_key:get`: `id` (`aky_...`), `name`, `keyPrefix`, `keySuffix`, `expiresAt`, `createdAt`. **Nunca** retornar a chave.
- `POST` retorna, além do acima, `securityKey` (chave em texto puro, grupo `api_key:post`) **uma única vez**; nunca persistida nem recuperável depois.

## Requisitos de Qualidade
- [x] Integração: `ApiKeyApiTest` verde (POST mostra a chave só uma vez, collection/GET/PATCH/DELETE, 404, escopo)
- [x] Unitário: `ApiKeyIssuer` gera `sk_` + 32 alfanuméricos e guarda apenas hash/prefixo/sufixo

## Restrições Técnicas
- Mover o `#[ApiResource]` de `ApiKeyResource` para a entidade `ApiKey` com `#[Groups]`; remover `ApiKeyInput`, `ApiKeyOutput`, `ApiKeyPatchInput`, `ApiKeyResource`.
- `securityKey` (texto puro) é transitória: exibir somente no POST e nunca persistir. Implementar como propriedade não mapeada pelo Doctrine (não vira coluna).
- Subresource POST usa `provider: CreateProvider::class` + `Link` para `project`; construtor sem `Project`.
- Manter a validação de escopo no `ApiKeyDeleteProcessor`.

## Revisão (aprovada)

- `createdAt` não possui `#[Groups]` e portanto não é serializado em `api_key:get`, embora o contrato de saída exija `createdAt`.
- `keyHash` está nos grupos `api_key:get`/`api_key:post` e é exposto na resposta; o contrato lista apenas `id`, `name`, `keyPrefix`, `keySuffix`, `expiresAt`, `createdAt`.
- `projectId` é verificado em `ApiKeyApiTest`, mas a associação `project` não expõe campo `projectId`.
- POST subresource não usa `provider: CreateProvider::class` + `Link` e o construtor recebe `Project`, contrariando a restrição técnica.
