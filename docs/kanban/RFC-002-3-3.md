# Segregar a listagem de Contractors por parceiro

No `ContractorCollectionProvider` (`GET /partners/{partnerId}/contractors`), garantir que a chave de parceiro liste apenas os contractors do seu próprio Partner, retornando 403/404 quando o `partnerId` for de outro parceiro.
