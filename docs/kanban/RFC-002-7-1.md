# Testar isolamento multi-tenant de Partners

Cobrir, em Partners, as quatro operações (`GET /partners`, `GET /partners/{id}`, `PATCH /partners/{id}`, `DELETE /partners/{id}`): a Master Key acessa/modifica qualquer Partner; a chave de parceiro acessa/modifica apenas o próprio Partner; acessos de um parceiro ao Partner de outro retornam 403/404.
