# Segregar a exclusão de ApiKeys por parceiro

No `ApiKeyDeleteProcessor` (`DELETE /api-keys/{id}`), a checagem de escopo já existe mas nega com `UnauthorizedHttpException` (401). Alinhar com a RFC para retornar 403/404 quando a API Key pertencer a um projeto de outro Partner (a Master Key continua excluindo qualquer API Key).
