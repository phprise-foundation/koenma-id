# Segregar a listagem de Projects por parceiro

No `ProjectCollectionProvider` (`GET /partners/{partnerId}/projects`), garantir que a chave de parceiro liste apenas os projetos do seu próprio Partner, retornando 403/404 quando o `partnerId` for de outro parceiro.
