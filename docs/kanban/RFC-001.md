# Refatoração de DTOs para Entidades Diretas (Fase 1.6)

## Contexto e Problema
Atualmente, o projeto utiliza DTOs separados de Input/Output para a maioria das entidades (`Project`, `Contractor`, `User`, `ApiKey`), enquanto `Partner` já foi migrado com sucesso para entidades diretas com `#[ApiResource]` e `#[Groups]`. Há um WIP pendente que precisa ser concluído para unificar a arquitetura em torno de entidades diretas e restaurar a suíte de testes.

## Valor de Negócio
Padronizar a API em torno de entidades diretas com API Platform reduz a complexidade e código boilerplate, aproveita nativamente o Serializer do Symfony com groups e garante que a base de código seja limpa, coesa e totalmente testável.

## Requisitos de Alto Nível
- Concluir a migração de `Project`, `Contractor`, `User` e `ApiKey` para entidades diretas com `#[ApiResource]` e `#[Groups]`.
- Garantir o correto funcionamento de subresources e resolução de IDs prefixados via `UriVariableTransformer` e `Normalizer`.
- Remover artefatos temporários da POC (`Gadget`, `Widget`, `SubresourceProbeTest`, etc.).
- Restaurar a suíte de testes para 100% verde.

## Restrições e Dependências
- Manter ValueObjects de ID prefixado e Doctrine CustomTypes existentes.
- Respeitar a doutrina e as regras estabelecidas na documentação do projeto.
