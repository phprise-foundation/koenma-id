# User — migrar DTOs para entidade direta

## Contrato de Entrada
- `POST /contractors/{contractorId}/users` (requer `X-Security-Key` válido do parceiro dono ou Master): `{ username: string (3..180), emailAddress: string (email, max 255), password: string (8..255) }`.
- `PATCH /users/{id}`: `{ username?, emailAddress?, password? }`.
- `contractorId`: ID prefixado do Contractor (`cnt_...`).

## Contrato de Saída
- `GET /contractors/{contractorId}/users`, `GET /users/{id}` e respostas de POST/PATCH serializam a entidade `User` no grupo `user:get`: `id` (`usr_...`), `username`, `emailAddress`, `emailVerified`, `active`, `createdAt`. **Nunca** expor o hash da senha.
- `404` para Contractor/User inexistente ou soft-deletado; `409` para username duplicado no mesmo Contractor; `401` para chave de segurança inválida.

## Requisitos de Qualidade
- [ ] Integração: `UserApiTest` verde (POST via security key, GET collection, GET/PATCH, 404, escopo)
- [ ] Unitário: `UserRegistrar` valida security key/username; senha em texto puro é hasheada (nunca persiste em claro)

## Restrições Técnicas
- Mover o `#[ApiResource]` de `UserResource` para a entidade `User` com `#[Groups]`; remover `UserInput`, `UserOutput`, `UserPatchInput`, `UserResource`.
- O `password` do payload (texto puro) não pode ser serializado no grupo `user:get`; o hash é persistido via `changePassword()` no processor/registrar.
- Subresource POST usa `provider: CreateProvider::class` + `Link` para `contractor`; construtor sem `Contractor`.
- A validação de security key (`SecurityKeyContext`) permanece no `UserRegistrar`/processor.

## Revisão (reprovada)

- Falta o import `use ApiPlatform\Metadata\ApiResource;` na entidade `User`. Sem ele, a anotação `#[ApiResource]` resolve para `Phprise\KoenmaID\Entity\ApiResource` (classe inexistente) e é silenciosamente ignorada, logo nenhuma rota `/users` nem `/contractors/{contractorId}/users` é registrada (`debug:router` não lista rotas de User; `debug:api-resource` retorna "No resources found"). Resultado: 10 falhas em `UserApiTest`/`UserRegistrarTest` com "No route found".
