# Segregar a exclusão de Projects por parceiro

Criar o `DELETE /projects/{id}` (operação `Delete` em `Project` com `ProjectDeleteProcessor`): a Master Key exclui qualquer Project e a chave de parceiro exclui apenas Projects do próprio Partner, retornando 403/404 quando o projeto for de outro parceiro.
