# Testar isolamento multi-tenant de Contractors

Cobrir, em Contractors, as quatro operações (`GET /partners/{partnerId}/contractors`, `GET /contractors/{id}`, `PATCH /contractors/{id}`, `DELETE /contractors/{id}`): a Master Key acessa/modifica qualquer Contractor; a chave de parceiro acessa/modifica apenas Contractors do próprio Partner; acessos de um parceiro a Contractors de outro Partner retornam 403/404.
