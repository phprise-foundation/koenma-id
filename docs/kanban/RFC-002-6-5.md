# Segregar a exclusão de Users por parceiro

Criar o `DELETE /users/{id}` (operação `Delete` em `User` com `UserDeleteProcessor`): a Master Key exclui qualquer User e a chave de parceiro exclui apenas Users de contractors do próprio Partner, retornando 403/404 quando o usuário for de outro parceiro.
