# Testar isolamento multi-tenant de Projects

Cobrir, em Projects, as quatro operações (`GET /partners/{partnerId}/projects`, `GET /projects/{id}`, `PATCH /projects/{id}`, `DELETE /projects/{id}`): a Master Key acessa/modifica qualquer Project; a chave de parceiro acessa/modifica apenas Projects do próprio Partner; acessos de um parceiro a Projects de outro Partner retornam 403/404.
