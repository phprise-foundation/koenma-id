# Testar isolamento multi-tenant de ApiKeys

Cobrir, em ApiKeys, as quatro operações (`GET /projects/{projectId}/api-keys`, `GET /api-keys/{id}`, `PATCH /api-keys/{id}`, `DELETE /api-keys/{id}`): a Master Key acessa/modifica qualquer ApiKey; a chave de parceiro acessa/modifica apenas ApiKeys de projetos do próprio Partner; acessos de um parceiro a ApiKeys de projetos de outro Partner retornam 403/404.
