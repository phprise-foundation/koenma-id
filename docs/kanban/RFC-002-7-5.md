# Testar isolamento multi-tenant de Users

Cobrir, em Users, as quatro operações (`GET /contractors/{contractorId}/users`, `GET /users/{id}`, `PATCH /users/{id}`, `DELETE /users/{id}`): a Master Key acessa/modifica qualquer User; a chave de parceiro acessa/modifica apenas Users de contractors do próprio Partner; acessos de um parceiro a Users de contractors de outro Partner retornam 403/404.
